# Mini 声色片场

SillyTavern 酒馆助手**全局脚本**：玩任何一张卡的时候，点场记板抽一出情趣小剧场（两个成年人约好玩的角色扮演 / cosplay），插进正文，正在聊的角色带着自己的性格演出来。⚠️ NSFW，18+。

- 男性向（琥珀场记板）和女性向（粉红场记板）是两份脚本，题材一样、抽到的概率不一样，广场各看各的。可以只装一个，也可以都装。
- 抽：挑档位（暧昧 / 涩涩 / 重口），点题材或者随便抽，每一格不喜欢可以单独重抽。
- AI 扩写成一页带三幕和台词的小剧本，或者自己写；都存进剧本夹（所有聊天、所有卡通用）。
- 插进正文：「让 ta 提议」或「直接开演」；演的时候有「下一幕」「收工」。只走提示词注入，不改你卡里的楼层。
- 剧本广场：发自己的（署名或匿名）、拿别人的去演、点赞、演完晒一句、改编再发。

## 装

酒馆助手 → 脚本库 → 全局脚本 → 导入：

- 在线版（推荐，作者发版你不用重导）：男性向 [`mini-male.json`](mini-male.json)，女性向 [`mini-female.json`](mini-female.json)
- 离线版（脚本全部内嵌，不会更新；广场仍要联网）：[`mini-male-offline.json`](mini-male-offline.json)、[`mini-female-offline.json`](mini-female-offline.json)
- `dist/mini.js`：脚本的完整代码。在线版按提交号从这里取，玩家能审到实际运行的代码。

场记板拖丢了：快速回复栏点「🎬 Mini 片场」（女性向是「🎀 Mini 片场」）。
